## Accessibility

The site is designed to make the written portfolio and resume usable without relying on the interactive network visualization. The text resume provides a direct, readable alternative to the visual presentation. Accessibility improvements should preserve clear headings, descriptive link text, visible keyboard focus, sufficient color contrast, and a usable small-screen layout. Interactive graphics should always have a meaningful text summary and a non-pointer way to access essential information.

To report an accessibility issue or request another format, contact [Taggert by email](mailto:tolson01@calpoly.edu).
